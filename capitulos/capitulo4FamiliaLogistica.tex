	\chapter {Família Logística}
	
	Neste capítulo, a família logística $F_\mu()=\mu\/x(1-x)$ será explorada conforme mudanças no parâmetro $\mu$, a fim de entender como a dinâmica se comporta no intervalo $0<x<1$. Essa família de funções ilustram muitos dos mais importantes fenômenos que ocorrem em sistemas dinâmicos.
	
	\begin{proposicao}
		Para a família logística $F_\mu()=\mu\/x(1-x)$
		
		1. $F_\mu(0) = F_\mu(1) = 0$ e $F_\mu(p_\mu) = p_\mu$, onde $p_\mu = \dfrac{\mu - 1}{\mu}$ é o ponto fixo. \\
		\indent 2. $0<p_\mu<1$ se $\mu > 1$. 
	\end{proposicao}
	
	\begin{prova}
		$F_\mu(0) = \mu\/0(1-0) = F_\mu(1) = \mu\/(1-1) = 0.$ Como $p_\mu$ é ponto fixo, então $F_\mu(p_\mu) = p_\mu.$ \\\\
	    Para que $0<p_\mu<1$ temos $0<1-\frac{1}{\mu}<1 \implies 0<\frac{1}{\mu}<1 \implies \mu>1.$		
	\end{prova}
